# hack-hack

Next.js 15 (App Router) + TypeScript + Tailwind. Ready to deploy on Vercel.

## Local dev

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this repo to GitHub (already done if you're reading this on GitHub).
2. Go to https://vercel.com/new and import the `NamishM123/hack-hack` repo.
3. Vercel auto-detects Next.js — no settings to change. Click **Deploy**.

Or via CLI:

```bash
npm i -g vercel
vercel        # preview
vercel --prod # production
```
